## Project Overview

"This platform is a one-stop solution for trading newly deployed tokens, eliminating the need for users to switch between multiple platforms."

"This platform streamlines this by consolidating all essential tools and data into a single dashboard, making trading seamless and efficient."

---

## Problem Statement

"Before trading in newly deployed token users must verify scams, check tokenomics, check socials, assess honeypot risks, review charts, and more across different platforms which makes the process tedious and time-consuming."

> "The Telegram bot faced challenges such as low adoption due to security concerns and users needing to switch platforms for information."

## User Interviews

"With client's help, I connected with the users indulged in this crypto trading space to understand their needs and mental model to come-up with a user friendly solution."

Goal: "Understand how people trade newly deployed tokens, their pain points, and identify the factors that influence their decisions."

### Key Insights

"After talking to 5 users i got many insights that needed to be considered in order to design a user friendly solution along with essential factors considered for deciding which tokens to trade."

**Essential Information for Decision-Making:**

1. Reviewing the token's white paper/tokenomics.
2. Analyzing social media presence and engagement.
3. Checking token data on platforms like CoinMarketCap.
4. Verifying security and ensuring it's not a scam (e.g., using Honeypot checks).
5. Tracking the token's traction and growth over time.

**Other insights:**

1. Conduct personal due diligence and research.
2. Gathering of information through word-of-mouth, community recommendations, or social media (e.g., Twitter).

### Pain Points

- **Frequent Platform Switching:** Users need to navigate multiple platforms to gather information on newly deployed tokens.
- **Missed Opportunities:** The fast-moving market makes it hard to gather information in time, leading to missed opportunities.
- **Time-Consuming Process:** The constant back-and-forth between different platforms slows down the decision-making process.
- **Lack of Centralized Information:** There's no single place to get info on newly deployed tokens, making it time-consuming and inefficient.

"After talking to the users, I connected with the client to discuss the insights that I got from the user interviews and to define the scope for the MVP."

## Feature: Multi Buy/Sell of Tokens

"This features allows users to buy/sell multiple tokens in a single trade."

**Need for this:**

- "Users can save up the gas fees by bulk trading tokens instead of trading individually."
- "Since trading with newly deployed tokens is very rapid, the user need to make a trade very quickly in order to make profits."
- "By consolidating purchases into one transaction, users can respond swiftly to rapid market movements and secure tokens before they sell out."
